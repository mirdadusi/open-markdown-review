# Support

Open Markdown Review is community-supported open-source software.

## Before reporting a problem

1. Read the [README](https://github.com/mirdadusi/open-markdown-review#readme), relevant [release notes](https://github.com/mirdadusi/open-markdown-review/blob/main/docs/releases/0.5.6.md), and [implementation status](https://github.com/mirdadusi/open-markdown-review/blob/main/spec/IMPLEMENTATION-STATUS.md).
2. In VS Code run **Markdown Review: Show Performance Diagnostics** when the problem concerns opening, refresh, or shared-folder latency.
3. Confirm the extension version, VS Code version, operating system, storage type, and whether the problem is reproducible in a small review without confidential content.

## Where to ask or report

- Use [GitHub Issues](https://github.com/mirdadusi/open-markdown-review/issues) for reproducible defects, usability problems, and feature proposals.
- Use the [protocol specification](https://github.com/mirdadusi/open-markdown-review/blob/main/spec/PROTOCOL-0.5.md) and [implementer checklist](https://github.com/mirdadusi/open-markdown-review/blob/main/protocol/IMPLEMENTER-CHECKLIST.md) when implementing an independent client.
- Follow the private reporting path in [SECURITY.md](https://github.com/mirdadusi/open-markdown-review/blob/main/SECURITY.md) for vulnerabilities.

Do not publish private review packages or sensitive documents. This release has documented qualification limits and is not presented as a qualified professional-pilot build.
