# Open Markdown Review 0.5.5

Regular release with known limitations; **not approved for the professional pilot**. This release adds explicit update controls and an ordered public-to-enterprise delivery contract. Review behavior, schemas and framework-neutral core wire version 0.5.0 are unchanged.

## Update behavior

- Public `mirdadusi.open-markdown-review` installations use VS Code's native Visual Studio Marketplace update service. VS Code selects the correct target package, applies its rollout delay, respects per-extension and global update settings, and can be centrally governed by enterprise policy.
- **Markdown Review: Check for Updates** invokes VS Code's Marketplace update check. **Open Update Source** opens the trusted Marketplace item. The public extension does not independently download or install a public VSIX.
- The enterprise derivative uses the same update client with a separate, checked-in GitHub Enterprise source identity. It selects `win32-x64` only on Windows x64 and `portable` elsewhere, validates the exact release/tag/repository/asset pair, bounds all responses, never forwards an authentication token to a redirect host, verifies the adjacent SHA-256 file, and only then asks VS Code to install the VSIX.
- Scheduled enterprise checks are optional, run at most daily after activation, use a bounded retry delay, and can be disabled through `openMarkdownReview.updateChecks.enabled`. Manual checks remain available.
- Enterprise publication is ordered after the public Marketplace publication. The enterprise release gate must observe the same version under `mirdadusi.open-markdown-review` before it can publish independently built `advanta-czechia` artifacts.

## Installation and updates

Install the public package from the Visual Studio Marketplace:

```sh
code --install-extension mirdadusi.open-markdown-review
```

Enabled Marketplace extensions update automatically unless the user or administrator changes VS Code's `extensions.autoCheckUpdates`, `extensions.autoUpdate`, update delay, or per-extension Auto Update setting. Use the extension context menu or Command Palette to trigger an immediate check.

For manual or offline installation, use `open-markdown-review-0.5.5-win32-x64.vsix` on Windows x64 and `open-markdown-review-0.5.5-portable.vsix` on other supported VS Code platforms. Verify the adjacent SHA-256 file before installing through **Extensions: Install from VSIX**.

## Compatibility and limitations

This release does not change events, manifests, revisions, browser clients, review permissions, storage layout, or the single-source-of-truth model. Review packages created by 0.5.3 through 0.5.5 therefore use the same declared protocol behavior.

- **SMB remains untested**, because an authorized CI-only SMB share is unavailable. No SMB compatibility or performance claim is made.
- **Professional-pilot qualification remains incomplete.** The authoritative open gates are recorded in [implementation status](../../spec/IMPLEMENTATION-STATUS.md) and [acceptance criteria](../../spec/ACCEPTANCE.md).
- Reviewer identities remain self-asserted and events unsigned. Role restrictions are workflow rules rather than authenticated authorization.
- Marketplace availability, automatic updates, and rollout timing depend on VS Code settings, applicable enterprise policy, proxy/firewall access, and the Marketplace service.
- Enterprise self-update requires access to the configured GitHub Enterprise release and either a VS Code GitHub Enterprise session or compatible GitHub CLI authentication for a private repository.

See the [security model](../../SECURITY.md), [Marketplace publishing runbook](../MARKETPLACE-PUBLISHING.md), and [support guide](../../SUPPORT.md).
