# Open Markdown Review 0.6.5

- Bundle Windows x64, macOS ARM64 and Linux x64 Go companions in both VSIX packages. Review creation copies only selected launchers into the destination; no separate companion download or participant runtime installation is required.
- Add invited reviewer email lists, initiator-only later invitations, and per-reviewer Finish/Reopen progress. Email identity remains self-asserted.
- Guide finding processing through the creator workbench, published-fix evidence and reviewer verification, while preserving existing comments and source anchors.
- Export a review PDF with native comment annotations and reviewer progress, or a clean document-only PDF. Improve tables, images, Unicode text and document links.
- Keep reading controls beside Export PDF, without an extra document header. Add bounded continuous reading, precise document/heading/finding navigation, and prevent stacked navigation panels from covering discussions in narrow windows.
- Upgrade existing HTML and Go launchers with recoverable backups and exact-byte evidence-preservation checks.
- Keep public extension updates in VS Code's native Marketplace workflow. Update bundled Go and build/schema dependencies with security fixes.

The public release contains the portable and Windows x64 VSIX packages and their SHA-256 files only. Each VSIX includes all three Go companions. The project is licensed under MIT; M.I.R.D.A. is a philosophy, not an additional license.

Core protocol version: **0.6.0**. Existing 0.5 and legacy 0.4 packages retain their original interpretation; no review history is silently converted. Real SMB shares remain untested. Managed-browser policies, executable signing/notarization and synchronized-folder qualification have limits. See the [implementation and qualification status](../../spec/IMPLEMENTATION-STATUS.md).

## Validation

After the source snapshot was committed, the exact complete VSIX packages passed native Windows x64 and Linux x64 CI qualification and local macOS ARM64 qualification. Checks covered isolated VS Code installation, offline review creation with all three bundled companions, browser collaboration, PDF export, native Go integrity and source/binary vulnerability scans. Real SMB and managed-endpoint qualification remain separate.
