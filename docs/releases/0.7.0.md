# Open Markdown Review 0.7.0

- Choose an export snapshot, A4 portrait layout, an optional cover, and a document list. The public release bundles only the generic **Default** template. Optional custom CSS/JSON imports remain supported.
- Read comments and nested replies in the PDF comments panel without serialized workflow records. Acrobat recognizes the exported finding statuses in comment review history. Copy network paths without treating them as broken archive links.
- Edit your own comments and replies on compatible reviews. Previous wording remains in the append-only history.
- Filter findings by decision, discussion status and snapshot; preview and reuse published fixes or publish updated documents with progress. The reader and export follow chapter links.
- Improve in-document navigation and render self-contained SVGs with supported embedded raster images. External or active SVG content is still blocked.

Both VSIX variants include Go companions for Windows x64, macOS arm64 and Linux x64. The wire protocol remains 0.6.0. Installation does not change existing reviews or PDFs.

SMB remains untested. See the [implementation and qualification status](../../spec/IMPLEMENTATION-STATUS.md).
