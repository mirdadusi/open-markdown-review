# Open Markdown Review 0.5.1

Regular release with known limitations; **not approved for the professional pilot**. This release adds optional Slidev static review through three separate layers: framework-neutral core protocol, versioned presentation profile, and a shared client adapter. Core wire version remains 0.5.0.

## Added

- A concrete [Slidev profile specification](../../spec/SLIDEV-PROFILE-V1.md), JSON schema and immutable schema/descriptor/resource bindings. Older or unsupported clients fail closed instead of silently treating a presentation as ordinary Markdown.
- Shared VS Code/CLI authoring with explicit project trust, pinned Slidev 52.19.1, automatic local `src:` imports/ranges, repeated-import identities, and include/exclude speaker-note policy.
- Frozen themed slide images, slide navigation, selectable exact source text, whole-slide visual comments and source wording comments in the same VS Code/HTML toolbox. Replies, decisions, resolutions, suggestions and review approval/rejection reuse core events.
- Audit PDFs containing all slide images, included notes, frozen source, discussion, replies and decisions, with profile/schema/image hashes in the exact inventory. Opening or reviewing a package does not execute Slidev or contact a review server.
- Parser/schema/security regression tests and a real Slidev-to-browser-to-PDF fixture, included in Linux and Windows CI. CRLF source selection, repeated visual targets, note redaction and no participant network requests are checked.

## Installation

- Windows x64: `open-markdown-review-0.5.1-win32-x64.vsix`.
- Other supported VS Code platforms: `open-markdown-review-0.5.1-portable.vsix`.

Both assets have SHA-256 checksum files and use standard VSIX metadata, without a pre-release marker. Install through **Extensions: Install from VSIX**. Browser participants receive the review folder with `OpenMarkdownReview.html`; they install no Slidev runtime. Existing HTML entry files are executable clients and require an explicitly approved, backed-up update to obtain the new adapter.

Only Slidev authors install the matching project-local renderer/theme/Playwright runtime. See the [creation guide](../SLIDEV.md). The trusted author-side build may briefly start Slidev's local build server; participant review remains file-based/serverless.

## Known limitations

- **Professional-pilot qualification remains incomplete.** The existing Mermaid interruption, cancellation/filesystem safety, Windows native browser permission, performance and independent usability gates remain open. A regular release label does not override [release-qualification.json](../../release-qualification.json).
- **SMB testing is skipped and remains untested**, as previously requested because an authorized CI-only share is unavailable. Shared-drive behavior is not certified; no SMB functionality was removed.
- Slidev v1 reviews static exports, not interactive components, animation timing, video or separate click states. It does not provide rectangular pixel anchors, pixel-to-word mapping or a reproducible build/dependency archive. Custom preparsers/addons and disabled/hidden slides are rejected.
- Authors must inspect captured pages before sharing. Frozen source/assets and rendered views are independently hashed, not a proof of honest rendering or byte-identical remote dependency use. Notes exclusion removes trailing speaker-note comments, not every possible secret or component-rendered text. Redacted source cannot be automatically patched back to a nonmatching original file.
- The isolated authoring test/example runtime includes two recorded, unpatched upstream `image-size` advisories in the unused PPTX export path. It is not shipped in the client. The application audit remains unmodified; the fixture accepts only the specifically documented advisories and must not be used for PPTX exports.
- Reviewer identities remain self-asserted. Audit hashes do not authenticate reviewers, sign approvals or establish that disconnected participants have synchronized.

The 0.5.0 tag, binaries and checksums are unchanged.
