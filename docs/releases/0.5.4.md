# Open Markdown Review 0.5.4

Regular release with known limitations; **not approved for the professional pilot**. This release prepares the existing 0.5.3 implementation for a clear public Visual Studio Marketplace presentation. Review behavior and core wire version 0.5.0 are unchanged.

## Marketplace presentation

- Adds an original 256-pixel Marketplace icon and light-theme screenshots of review setup, the VS Code review toolbox, and the portable browser participant experience.
- Reworks the README opening so an evaluator can understand the local-first model, installation choices, supported content, single source of truth, and current qualification status before entering the detailed documentation.
- Adds focused Marketplace metadata, search keywords, free-pricing declaration, public support guidance, and a private vulnerability-reporting path.
- Adds a deterministic presentation check for required files, screenshot references, icon size, public metadata, version consistency, and accidental internal repository markers.
- Adds repeatable Marketplace packaging for a portable VSIX and a Windows x64 VSIX. Each package receives a SHA-256 checksum; the Marketplace build allows `vsce` to rewrite repository-relative documentation links for the hosted listing.
- Documents a manual first-publication process using a short-lived, least-privilege Azure DevOps personal access token. No CI workflow or long-lived repository secret is introduced.

## Installation

After Marketplace publication, open **Extensions** in VS Code and search for **Open Markdown Review**, or run:

```sh
code --install-extension mirdadusi.open-markdown-review
```

For manual or offline installation, use `open-markdown-review-0.5.4-win32-x64.vsix` on Windows x64 and `open-markdown-review-0.5.4-portable.vsix` on other supported VS Code platforms. Verify the adjacent SHA-256 file before installing through **Extensions: Install from VSIX**.

Browser-only participants receive the complete review folder and open its review-named HTML launcher; they do not install a Marketplace extension.

## Compatibility and limitations

This release does not change schemas, event types, revision format, browser behavior, VS Code commands, or protocol capabilities. Packages created by 0.5.3 and 0.5.4 therefore use the same declared protocol behavior. Existing 0.4 packages retain the legacy reader and are not silently migrated.

- **SMB remains untested**, because an authorized CI-only SMB share is unavailable. No SMB compatibility or performance claim is made.
- **Professional-pilot qualification remains incomplete.** The authoritative open gates are recorded in [implementation status](../../spec/IMPLEMENTATION-STATUS.md) and [acceptance criteria](../../spec/ACCEPTANCE.md).
- Reviewer identities remain self-asserted and events unsigned. Role restrictions are consistent workflow rules, not authenticated authorization.
- Browser access depends on Chrome/Edge File System Access support, user permission, and applicable enterprise policy. A local HTML file cannot silently inherit Windows identity or access neighboring folders.

See the complete behavior introduced in [0.5.3](0.5.3.md), the [security model](../../SECURITY.md), and the [support guide](../../SUPPORT.md).
